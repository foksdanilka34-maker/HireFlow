# BotMessagesDropped (warning)

**Что значит.** За 10 минут бот отбросил хотя бы одно сообщение (метрика `hireflow_bot_messages_dropped_total`):
очередь обработки, в которую попало сообщение кандидата (до 100 сообщений), заполнена, бот не успевает их обработать.
**Влияние:** сообщения кандидата потеряны, ответа на них не будет.

## Как проверить
- Grafana, дашборд «HireFlow»: «Ошибки бота, в минуту», «Сообщения бота, в минуту».
- Логи (Loki): `{service_name="hireflow-bot"} |= "Message dropped"`.
- Медленно ли отвечает API: горит ли [ApiLatencyHigh](ApiLatencyHigh.md), панель «HTTP API: p95 по маршруту».

## Частые причины
- API отвечает медленно, и обработка каждого сообщения затягивается.
- Кандидат (или бот-спамер) шлёт очень много сообщений подряд.

## Что делать
1. API медленный — разбираться по [ApiLatencyHigh](ApiLatencyHigh.md).
2. Поток сообщений от одного пользователя — проверить логи бота; при спаме отклик всё равно ограничен
   дневным лимитом загрузок.

## Когда эскалировать
Сообщения отбрасываются больше часа — разработчику бота.
