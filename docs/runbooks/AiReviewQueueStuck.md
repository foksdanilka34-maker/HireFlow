# AiReviewQueueStuck

Пограничные отклики ожидают проверки ИИ больше пяти минут. Проверьте доступность `llama-server` на `http://127.0.0.1:18081/health`, статус API и логи с типами ошибок, не извлекая текст резюме. На Windows `make up` запускает локальную модель, если проверка включена в `.env`. Убедитесь, что модель загружена и есть память на GPU. После восстановления задачи повторяются автоматически; после исчерпания попыток отклик передаётся рекрутеру с пометкой об ошибке.
