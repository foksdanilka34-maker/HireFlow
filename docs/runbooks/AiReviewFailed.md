# AiReviewFailed

Одна или несколько задач проверки ИИ исчерпали попытки. Отклики автоматически переданы рекрутеру с пометкой «проверка ИИ недоступна»; автоматического отказа из-за сбоя нет. Проверьте доступность локальной модели, журнал API и корректность настройки имени модели. Не добавляйте текст резюме и ответы модели в диагностические журналы.
