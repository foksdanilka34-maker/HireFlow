# ApiLatencyHigh (warning)

**Что значит.** За 15 минут меньше 95% запросов к API (без `/health*`) выполнились быстрее 1 с, при не
меньше 20 запросах. SLO задержки — 95% запросов быстрее 1 с.
**Влияние:** бот медленно отвечает кандидатам, кабинет рекрутера тормозит.

## Как проверить
- Grafana, дашборд «HireFlow»: «Доля запросов к API быстрее 1 с», «HTTP API: p95 по маршруту».
- Медленные маршруты (Prometheus):
  `histogram_quantile(0.95, sum by (le, http_route) (rate(http_server_request_duration_seconds_bucket{service_name="hireflow-api"}[15m])))`
- Трейсы в Tempo (Grafana → Explore → Tempo, TraceQL): `{resource.service.name="hireflow-api" && duration > 1s}` —
  видно, где время: SQL или код.
- Нагрузка на контейнеры: `docker stats --no-stream`.

## Частые причины
- Медленные SQL-запросы (в трейсе длинные спаны `postgresql`).
- Большие резюме: чтение PDF/DOCX при отклике.
- Нехватка CPU или памяти на хосте.

## Что делать
1. По трейсам найти медленный участок.
2. Нехватка ресурсов — освободить хост или увеличить ресурсы.
3. Медленный запрос — задача разработчику (индекс, запрос).

## Когда эскалировать
Задержка не снижается час или одновременно горит `ApiErrorBudgetFastBurn` — разработчику API.
