# HireFlow

HireFlow помогает рекрутеру проводить первичный отбор кандидатов. Кандидат отправляет резюме Telegram-боту, а система сопоставляет его с требованиями вакансии и передаёт отклик в кабинет рекрутера.

- Рекрутер создаёт вакансии; локальный ИИ помогает улучшить описание и предложить уточняющие вопросы.
- Бот принимает резюме в PDF или DOCX, помогает откликнуться и задаёт утверждённые вопросы.
- ИИ анализирует резюме и ответы, помогает рекрутеру улучшить вакансию; итоговое решение принимает рекрутер.
- ИИ работает на компьютере пользователя. Ответы модели нужно проверять: она может ошибаться.

## Стек и архитектура

- **Backend и бот:** C#, .NET 10, ASP.NET Core, Telegram Bot API.
- **Кабинет:** Blazor WebAssembly и Bootstrap.
- **Данные:** PostgreSQL и Entity Framework Core; файлы резюме хранятся локально.
- **ИИ:** локальная GGUF-модель через llama.cpp.
- **Запуск и наблюдаемость:** Docker Compose, OpenTelemetry, Prometheus, Grafana, Loki и Tempo.

Приложение разделено на API, Telegram-бота и веб-кабинет: бот и кабинет обращаются к API, а API работает с базой, файлами и моделью. Код API разделён на слои Domain, Application и Infrastructure; фоновые задачи и уведомления используют очередь в PostgreSQL.

## Запуск

Для Windows нужны Docker Desktop, установленный `llama.cpp` с GGUF-моделью и Telegram-бот от BotFather. При первом запуске программа запросит токен бота, при необходимости пути к модели и данные для входа рекрутера. Затем автоматически запустит модель и весь проект и откроет кабинет в браузере.

В папке проекта выполните:

```powershell
.\start.cmd
```
